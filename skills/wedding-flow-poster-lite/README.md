# Wedding Flow Poster Lite

把杂乱的婚礼资料交给 AI，先整理成**只适合海报展示的简洁流程**，确认无误后，再生成一张固定暖白纸张背景的 9:16 流程海报。

## 它只做两件事

1. 把口语、执行备注、重复内容清理成简短的海报流程；
2. 用户确认后，用真实 HTML/CSS 文字渲染成 1080×1920 PNG。

它不是婚礼执行单、会议纪要或策划方案。像“伴郎递麦克风”“督导提醒”“音乐”“来宾人数”“服装”“准备物品”等信息，不会进入 Lite 海报正文。

## 使用方式

### 第一步：发资料

可以直接粘贴很乱的婚礼流程。Skill 会只保留：

- 新人姓名
- 日期
- 时间
- 地点
- 简洁的流程名称

每一个流程项尽量是一行一个动作，例如：

```text
主持人开场
新郎入场
新娘入场
新人告白
交换戒指
父母登场
父亲致辞
合影
```

AI 会先把完整清稿给你确认，不会马上出图。

### 第二步：确认并生成

确认无误后回复：

> 确认，生成海报。

Skill 才会把**刚刚确认的简洁流程**渲染成 PNG，不会把原始资料里的执行备注重新塞回海报。

## 固定视觉

- 1080×1920，9:16
- 固定暖白纸张背景
- 主文字 `#302D29`
- 强调色 `#9B4C2E`
- 默认最多两种文字颜色
- 居中、留白、无时间轴、无卡片
- 真实 HTML/CSS 文字，不用 AI 画中文字

## 测试建议

在新的 Chat / Work 中上传整个 ZIP，让它读取 `SKILL.md` 后测试：

1. 发一段包含很多执行备注的婚礼资料；
2. 检查第一轮是否只输出“基本信息 + 简洁流程”，而不是完整婚礼纪要；
3. 检查像“伴郎递麦”“督导提醒”“服装”“音乐”“准备物品”等是否被排除；
4. 修改一个流程，确认它重新给完整清稿并继续等待确认；
5. 回复“确认，生成海报”，检查生成内容是否仍然只有简洁事件名称；
6. 第一条消息故意说“直接生成”，检查它是否仍坚持先确认。
